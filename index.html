Esta visualización representa una brecha de actualización teórica. Para determinar un descalce económico-financiero real deben incorporarse avance físico, certificación, montos efectivamente ejecutados, adecuaciones ya reconocidas y saldo contractual pendiente de ejecutar (ver "Preparado para v3" más abajo).

Preparado para v3

La arquitectura actual deja lugar para incorporar, sin rehacer el sistema: avance físico, certificación, monto ejecutado, monto pendiente, adecuaciones reconocidas, costos reales incurridos, flujo financiero y saldo contractual. Con esos datos, la "brecha de actualización" de hoy podrá evolucionar hacia un indicador real de descalce económico-financiero.

Metodología

  1. Datos oficiales ICC — INDEC, Gran Buenos Aires, base 1993=100.
  2. Variaciones calculadas a partir de índices, nunca sumando porcentajes mensuales.
  3. Umbral configurable — 5% por defecto, ajustable en el simulador.
  4. Corte automático al alcanzar o superar el umbral.
  5. Reinicio de acumulación desde cada corte registrado.
  6. Exposición calculada como indicador de análisis de gestión, no como valor contractual reconocido.
  7. Brecha de actualización, diferenciada expresamente del descalce contractual real.
