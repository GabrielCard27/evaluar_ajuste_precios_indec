Camino hacia futuras versiones

Esta V3 construye el modelo de información y decisión con datos de demostración internamente consistentes. La arquitectura (const OBRA = {contrato, planificacion, produccion, certificacion, costos, adecuaciones, flujoFinanciero, riesgos}) está preparada para reemplazar el JSON demo por datos reales — Excel, CSV, API o base de datos — sin rehacer el sistema.

Metodología

  1. ICC — fuente INDEC, índice oficial usado directamente cuando está disponible, nunca normalizado a 100.
  2. Adecuaciones — motor multiplicativo basado en índices: (Índice corte / Índice base − 1) × 100.
  3. Producción — avance previsto vs. real, datos de demostración editables.
  4. Costos — costo real vs. presupuesto, con Valor Ganado (PV / EV / AC).
  5. Equilibrio — integración de producción, certificación, costos, adecuaciones y saldo contractual.
  6. Proyección — EAC / ETC / VAC bajo tres escenarios, identificados como estimación, no certeza.
  7. Riesgo — señales configurables, combinando indicadores calculados y riesgos de demostración.
  8. Decisión — motor de señales de gestión que prioriza alertas críticas, no un promedio matemático.
